# Glance on Eywa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `glance watch` lights each configured LED from Eywa's client row, decoded with `eywa-api`; Glance's own hooks are gone.

**Architecture:** A new `src/eywa.rs` subscribes to Eywa on a background thread. It keeps `eywa_api::Row`s by id and sends the client states, as `Option<Clients>`, over a channel; `None` means disconnected. `agents::watch` maps each indicator's agent name to its client's `State`. The layout names agents as Eywa client names, not as a fixed enum.

**Tech Stack:** Rust 2024 (1.89), `eywa-api` (git), serde_json, `std::os::unix::net`, `std::sync::mpsc`.

**Spec:** `docs/superpowers/specs/2026-11-23-eywa-design.md`

## Global Constraints

- **Request:** `eywa_api::Request::subscribe("/", 1)`.
- **Socket:** `eywa_api::default_dir().join(eywa_api::API_SOCKET)`.
- **LEDs:** `State::NeedsInput` pulses and `State::Working` is steady. Anything else, or no row, is off.
- **Disconnected:** the LEDs go dark, Glance retries every 1 s, and it logs once when Eywa is lost and once when it reconnects.
- **Rejection:** an `error` message ends `glance watch` with its code and message.
- **Starting Eywa:** `eywa start` runs once, only when Glance launches and the socket isn't answering. It's skipped when `EYWA_DIR` is set.
- **Agent names** match `^[a-z0-9_-]+$`.
- **Checks:** `cargo fmt --check`, `cargo test --locked` and `cargo clippy --locked --all-targets -- -D warnings` pass after every task.

## Review Focus

1. **Eywa isn't running when Glance starts:** the LEDs stay dark until Eywa answers. Test: `eywa_starting_after_glance_is_picked_up`.
2. **Eywa restarts:** the LEDs go dark, then the new snapshot takes over. Test: `lost_connection_goes_dark_and_resubscribes`.
3. **A deliberate `eywa stop` mid-watch** isn't undone. Tests: `a_running_eywa_is_not_restarted_after_it_stops` and `eywa_is_started_at_launch_but_a_later_stop_is_respected`.
4. **A malformed line** leads to a resubscribe. Test: `malformed_line_resubscribes`.
5. **A configured agent that Eywa doesn't have** is warned about once and stays off. Test: `missing_agents_are_named_once`.

### Task 2: Subscribe to Eywa

**Files:**
- Create: `src/eywa.rs`, declared `#[cfg(target_os = "macos")]` in `main.rs`.
- Modify: `Cargo.toml`. Add `eywa-api`.

**Produces:**
- `pub type Clients = BTreeMap<String, eywa_api::State>`, keyed by client name, such as `"claude"`.
- `pub fn subscribe(path: PathBuf, retry: Duration, start: impl Fn() -> Result<()> + Send + 'static) -> Receiver<Result<Option<Clients>>>`. It sends:
  - `Some(clients)` whenever the clients change.
  - `None` once per outage.
  - `Err` on rejection, after which the thread ends.
- `pub fn start() -> Result<()>`, which runs `eywa start`, and the private `run_start(program: &OsStr)`.

- [ ] **Step 1: Write the failing tests.** They run against real `UnixListener`s in `std::env::temp_dir()`, and the server reads the request line and checks it equals `Request::subscribe("/", 1)` as a `Value`.
  - `subscription_sends_the_request_and_follows_changes`
  - `lost_connection_goes_dark_and_resubscribes`
  - `eywa_starting_after_glance_is_picked_up`
  - `malformed_line_resubscribes`
  - `rejection_ends_the_subscription`, where the error contains `bad_request: unknown view`
  - `eywa_is_started_at_launch_but_a_later_stop_is_respected`
  - `a_running_eywa_is_not_restarted_after_it_stops`
  - `unknown_messages_and_kinds_are_ignored`: a `heartbeat` message and a row of kind `robot` don't change `Clients`, and a client in an unknown state comes through as `State::Other`.
  - `start_command_reports_failure`, using `/usr/bin/true`, `/usr/bin/false` and a missing path.
- [ ] **Step 2: Run them.** Expected: compile errors.
- [ ] **Step 3: Implement.**

  - `Clients` is every row with `kind == Kind::Client`, with the leading `/` dropped from its id.
  - Log lines:
    - `Eywa isn't answering at <path>; running eywa start.`
    - `couldn't start Eywa: <e>. Waiting for it.`
    - `lost Eywa; reconnecting.`
